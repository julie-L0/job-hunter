# Learnings

## [LRN-20260902-001] 无私人信息提交的边界

**Priority**: medium
**Status**: resolved
**Area**: infra

### 内容
“无私人信息版”应指提交内容不包含个人凭证、真实业务数据或本机敏感路径，不应擅自替换项目现有的提交作者身份。项目归属和 Git 作者应保持用户原有配置，除非用户明确要求匿名化作者。

### 建议修复
提交前分别审查文件内容和 Git 元数据；仅在用户明确要求时修改作者或重写历史。

## [LRN-20260903-001] 日历完成态由岗位状态派生

**Priority**: medium
**Status**: resolved
**Area**: product

### 内容
关联岗位的日程不应要求用户重复维护完成状态。岗位当前状态达到或越过日程绑定阶段，或进入挂/offer 终态时，日历应自动将日程显示为已完成；日程数据本身继续保留。

### 建议修复
把完成态实现为前端派生状态，并让月历、当天详情和接下来列表共用同一个判定函数；不要为了视觉完成态修改或删除日程记录。
