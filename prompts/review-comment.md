输出 JSON，格式：
{
  "highlights": ["确实答得好的点，写清楚为什么好"],
  "problems": [
    {
      "point": "问题是什么",
      "evidence": "逐字记录里的原话，必须逐字引用，不许改写或编造",
      "fix": "下次这道题该怎么答，给具体说法而不是空泛建议"
    }
  ],
  "answerRewrites": [
    {
      "question": "面试官问的原问题",
      "betterAnswer": "结合候选人简历里真实存在的经历重写的回答，200字内"
    }
  ],
  "nextActions": ["面试后马上能做的准备动作"],
  "takeaway": "一句话结论，40字内，指出这场最该改的一件事"

要求：
- `evidence` 必须是逐字记录里出现过的原话。找不到原话支撑的问题就不要写。
- `betterAnswer` 只能用 JD 和简历里已有的事实，不许替候选人编造经历、数据或头衔。
- 逐字记录来自语音转写，有错别字和断句错误是正常的，按上下文理解，不要把转写错误当成回答问题。
- 宁少勿多：highlights 和 problems 各 2-4 条，answerRewrites 只挑答得最差的 1-3 题。
- 只点评这场面试暴露出来的问题，不评价简历本身。
